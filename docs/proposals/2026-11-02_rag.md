# Proposal: RAG index over the papers, scored against keyword search

From: build account, session rag. Date: 2026-11-02. Spec 2026-11-02 section B, task c024. Committed before any run. No stop for approval. Nothing below changes after the first scored result is seen.

## Corpus
- The 17 files with `included = yes` in `docs/context/literature/rag_corpus.csv` (16 papers, one supplement). sha256 checked, 17 of 17 match (commit d4fd350)
- No OUP or Wiley paper goes into the index, the gold set or any prompt
- PDFs in `staging/rag_corpus/`; extracted text, chunks, index and answer texts in `staging/rag/` (both git-ignored)

## Text and chunks
- Text per page with pypdf 6.21.4 (`extract_text`). Page number = PDF page index, from 1 (not the journal page number)
- Normalised text (used for chunks, BM25 and the quote check): Unicode NFKC; ligatures and soft hyphens removed; dashes and curly quotes mapped to ASCII; a hyphen at a line end between letters joined ("elon-\ngation" -> "elongation"); whitespace collapsed to one space
- Chunks inside one page: a page of at most 350 words is one chunk; a longer page is cut into 300-word windows with 50 words of overlap, and a last window under 100 words is merged into the one before. Each chunk carries paper key, page, DOI (from the csv)

## Retrievers
- RAG retriever: local embeddings, fastembed 0.9.1 with `BAAI/bge-small-en-v1.5` (384-d, ONNX, CPU), cosine similarity, query and passage forms of the model. Top k = 6 chunks go to the answerer
- Baseline: BM25 (k1 1.5, b 0.75) over the same chunks, plain Python. Tokens: lowercase runs of letters and digits, length 2 or more, no stop list
- Both rank chunks; a hit is a chunk whose (key, page) is a gold page

## Answerer
- One `claude -p` call per question through `agents/launcher.py` (pinned model and Claude Code version in `config/models.yaml`, strict model check, no tools). Effort medium, max turns 3
- Prompt: the question and the 6 chunks, each headed by key, page, DOI. System prompt `rag/prompts/answerer.md`: answer only from the chunks; quote verbatim; decline if the chunks do not contain the answer
- Output: one typed JSON action
  - `answer` {text (at most 60 words), quote (verbatim from one chunk, at most 40 words), key, page, doi}
  - `decline` {reason: `not in corpus`}
- Plain-Python check, no LLM:
  - The action and its fields are valid
  - The key is in the corpus, and the DOI equals the csv DOI for that key (empty for the 3 papers that print none)
  - The normalised quote, lowercased, occurs in the normalised, lowercased text of that page of that paper
- A failed check is reported as an unverified answer. Never repaired by hand

## Gold set (`rag/gold.yaml`), committed before any system run
- 25 questions on root kinematics and methods, written from the PDFs (page text), not from any system output. The retrievers are not run on the questions before the gold set is committed
- 20 answerable: key, page, quote of at most 25 words that supports the answer, short answer. Each gold quote passes the same check in code (a test). Optional `alt` pages where the same fact is stated, each with its own checked quote. At least 10 of the 16 papers used; the question does not contain its gold quote verbatim
- 5 out of corpus: the answer is only in an excluded paper. Correct outcome: decline. The entry holds the question and `expect: decline` only: no key, quote or answer from an excluded paper. Each is checked absent from the corpus by a keyword search over the extracted text (terms listed in the entry)

## Outcomes per question and run
- Answerable: `correct` (key and page equal gold or an alt page, quote verified, DOI equal); `wrong_source` (verified, other page); `unverified` (check failed); `declined`; `error` (no valid action)
- Out of corpus: `declined` (correct); `answered_verified`; `unverified`; `error`

## Metrics, computed in code (`rag/score.py`)
- Answer accuracy: `correct` / 20, per repeat; median and range over 3 repeats
- Verified-quote rate: verified answers / all answers given (all 25 questions)
- Decline precision: declines on out-of-corpus questions / all declines. Decline recall: declines on out-of-corpus / 5
- Agreement across repeats: fraction of the 25 questions with the same outcome in all 3 repeats
- Retrieval, on the 20 answerable, no LLM: gold page in the top 1 and top 5 for BM25 (the baseline) and for the embedding retriever; gold page in the top 6 (the answerer's context) for the embedding retriever
