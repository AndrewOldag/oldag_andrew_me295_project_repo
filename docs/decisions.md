- 2026-10-10: Measurement record (`docs/context/measurement_record.md`) is built from the tracker's three tracked chains (centre and two flanks), the stage log, frame times and the per-frame midline. - 2026-10-10: Checker definitions. Profiles are window means over frame pairs. Each check returns pass or fail, the value, the threshold and where it failed
  - Rigid-body invariance: run the measurement again on the same movie with a known rigid motion added (per-frame rotation about the frame-0 tip plus a translation, not entered in the stage log). Value: largest absolute difference between the two runs' window-mean strain-rate profiles, over s and over centre, plus and minus, in %/h. Where: s of that difference. Cost: one extra tracker run per window (both flanks and centre). Field-level rods are moved in the record and re-derived, with no tracker run
  - Tip-displacement closure: per frame pair, r = d(tip_world) - d(c_0 - c_b). tip_world is the tip from the midline source in image coordinates plus the stage log. c_0 - c_b is the tip relative to the most basal centre point tracked in every frame; the stage log cancels in it, and its change is the integrated strain rate and rotation along the midline. Assumes the basal tissue is fixed in the world. Value: |sum of r| over the window divided by the window duration, px/h. Where: s of the basal point and the frame pair with the largest residual. Cost: no extra tracker run
  - Plane-sections kinematics: residual(s) = mean(regr_plus - regr_minus) + mean(spacing x kappa_rate), the relation flank difference = -(flank spacing) x material curvature rate for constant width (sign as in the record conventions). Value: largest |residual| over s, in %/h. Where: s of that residual. Cost: no extra tracker run; needs the centre chain (`track_centre=True`), which is one more tracking pass inside the same run
  - Window means use only grid points covered by at least half of the frame pairs (`MIN_COVERAGE = 0.5`). Added after the first clean image-level rod: a point covered by 1 of 40 pairs gave a 1.6 %/h plane-sections residual where the covered profile was within 0.9 %/h
  - Reason: each check is a relation that holds for any correct measurement of a rod (rigid motion makes no strain; an anchored base makes the tip move by the integrated kinematics; plane sections tie the flank difference to the bending rate). None needs the truth, so the same checks run on real movies

- 2026-10-10: Remedy table (spec 2026-10-09, item 5; `measure/remedies.py`). A remedy is applied to the current run settings, the measurement is re-run (both the movie and its rigidly moved copy) and re-checked. Remedies stack

  | Remedy | Setting | What it changes | Carried out by |
  | :-- | :-- | :-- | :-- |
  | change_frame_stride | half / double | analysis frame stride, halved or doubled (half is refused at stride 1) | tracker input (`qb_track.py --stride`) |
  | enlarge_patch | 1.5x / 2x | tracker disk radius, 1.5 or 2 times the first run's radius (15 px -> 22 or 30 px) | tracker parameter `disk_radius` |
  | register_frames | none | rigid (Euclidean) registration of frame t to frame t-1 on the basal band of the root (60-100 % of the tracked length, 20 px band; OpenCV ECC), after the logged stage shift; applied to frames and midline before tracking | preprocessing before the tracker (`measure/preprocess.py`); the tracker has no registration |
  | smooth_midline | light / strong | Gaussian smoothing of the midline source along s (10 / 25 px) and over time (1 / 3 frames), before seeding and curvature | preprocessing of the midline source |
  | crop_or_mask | mask_second_root / crop_to_main_root | pixels outside a 45 px band around the midline (or outside the band's bounding box) set to background | preprocessing of the frames |
  | switch_midline_source | classical / ml | not available: synthetic rods have one midline source; the tracker repository has the ML midline only | none; returns "not available" |
  | use_width_free_ratio | none | not available: changes the reported quantity, not the measurement; no tracker setting | none; returns "not available" |

  - The spec says a remedy the tracker cannot carry out is removed from the list. Removing `switch_midline_source` and `use_width_free_ratio` is a list change and waits for Andrew; until then they return "not available" and are never imitated
  - `register_frames` assumes the basal tissue is fixed in the world, as closure does. After it, closure is not independent evidence on synthetic rods, whose background has no texture
  - Reason: remedies are re-runs with one changed setting, so the agent's choice is the only difference between runs
