## Project proposal

**Question.** Can an LLM agent, guided by deterministic beam-kinematics checks, decide when a strain-rate measurement of a growing root can be reported, repaired or must be declined, more reliably than a fixed script, a rule-based remedy tree and a single agent without the checks? A growing root is a slender rod that generates its own strain; its axial strain rate sets elongation and the difference across the section sets the rate of bending. The field is measured by image correlation on time-lapse movies and can fail silently. Claims are about agent behaviour only; kinematics only (no stress, stiffness or constitutive law).

**Users.** Groups that measure root or hypocotyl strain-rate fields from many movies. Today each profile is checked by eye (Youssef et al. 2018; Platre et al. 2024 lose 8-25 % of roots). The system returns accept, repair or decline with a reason, so review is limited to flagged cases.

**Why an agent.** A script always returns an answer. The test: can an agent name the fault, pick a remedy from a fixed list, and decline an untrustworthy result, judged by checks outside the model.

**System.** Dispatcher (LLM agent: root-by-window tasks, cost estimate, submission; built, 5a4767f). Tracker and midline net (tools; real-movie midline `net2_midline_ft2`). Checker (deterministic: rigid-body invariance, tip closure against the stage log, plane sections). Diagnostician (LLM agent: names the fault, picks one of 6 remedies, or declines). Auditor (LLM agent: batch review and report). One typed JSON action per call, executed by a plain-Python orchestrator. Human approval for compute budgets, threshold changes and deletes. Model `claude-opus-5-5`, Claude Code 2.1.310 pinned.

**Evaluation.** Synthetic rods with known fields and injected faults; real control windows for a noise floor; a real-movie subset; all 102 include-yes roots once. Scored set freeze v3 (tag `freeze-v3`, e1e672a; results 2ebd422): 51 rods on unseen seeds (accept_clean 18, accept_repaired 12, decline 21), LLM methods 3 repeats.

| Method | Balanced accuracy | False accepts | Unanimity over 3 repeats |
| :-- | :-- | --: | :-- |

**Main risks.** (1) The synthetic set cannot show repair skill: every v3 accept_repaired rod measures well without its remedy, and a v3.1 resizing found no fault that both degrades the field and is repaired on 3 of 3 seeds; the claim centres on accept versus decline. (2) Real windows: closure threshold 19 px/h from 41 control windows (synthetic 1.0); rigid invariance and plane sections reported, not gating. (3) Small samples: counts reported with rates.

## Related-work note (updated)
Lab report 1 note, unchanged. [ANDREW] papers from the spec-audit list, if any are added.

### Agent systems for scientific workflows
- Wei et al. 2025, From AI for Science to Agentic Science (arXiv:2508.14111). Four autonomy levels; provenance of tool versions and parameters called required; hallucination can be amplified between agents. Here: a level 2 system; each run records the freeze tag and commit
- Yao et al. 2023, ReAct (ICLR 2023; arXiv:2210.03629). Reason-act-observe loop over three typed calls. Reasoning errors, including repetitive loops, 47 % of ReAct failures (Table 2). Here: the same loop over a fixed action space; the single agent hit the step limit on 13 of 25 development runs (freeze v2)
- Geifman & El-Yaniv 2017, Selective classification (NeurIPS 2017; arXiv:1705.08500). Reject option; selective risk vs coverage. Here: decline is the reject option, false accepts the selective risk; coverage and abstention precision and recall are computed in freeze v3

### Setting: root kinematics tools
- KymoRod (Bastien et al. 2016), PatchTrack (Henry et al. 2023), Chavarría-Krauser et al. 2008, Krupař et al. 2026: each returns a velocity or strain-rate profile; trust in the profile is decided by a person after the run
- Quality control is manual: Youssef et al. 2018 checked profiles by eye; Platre et al. 2024 report roots lost but no automatic test of a measurement
- The checks come from kinematic relations in the same literature: flank REGR difference tied to the material curvature rate for a rod of constant width (Silk & Erickson 1978; Chavarría-Krauser 2006; Bastien et al. 2014)

### Synthesis
- The tracker stays fixed. This project adds the layer around it: deterministic checks that any correct rod measurement satisfies, an agent that names the fault and repairs or declines, and scoring with known truth
- New against these papers: whether a result can be trusted is decided by beam kinematics, not by the model's confidence
