Root manifest review

Before you start

  • One card per root position (experiment and chamber code). Each card shows the stitched movie at the start, middle and end. Movie with time opens a player with one frame every 15 min and the elapsed time on each frame; drag the slider to find when something happens, then press Set start or Set end to fill the usable window.
  • For each root: check the condition, choose Keep, Drop or Unsure, and add a note if anything looks wrong (second root in frame, root leaves the field, out of focus, drift).
  • Condition is pre-filled from the chamber code and is a guess. The c/m meaning in the 21 Jul folder and the cc/mc/mm meaning in the 27 Jul folder need your confirmation.
  • Root counts per folder do not match the earlier inventory (see the table below). Please say which is right.
  • 21 Jul: test1.dir holds no capture folders; only test2.dir (named timebefore_30) exists. 27 Jul: every root has one gap of about 40 min. This may be the transfer.
  • Usable window: if only part of a movie can be tracked, enter the hours to keep (e.g. from 0 to 12). Leave blank to keep the whole movie. The filter Notes mention a time limit lists the roots whose notes suggest one.
  • Answers save automatically to data/manifest/manifest_reviewed.csv. You can close the page and come back.
